viability%

        Measured data or prediction?
        
        
        Every line and KPI on the Plan view is a model prediction, even for a recipe that was run for real. Measured values appear only as grey points and as “Measured” under a KPI. The table compares how much real replicates of the same recipe differ from each other (the limit set by the lab data) with how far the model is off (the error the model adds).
        
      
        
      
        
    
        

    
        
      
        
        
        How accurate is it?
        
        
        Six real runs are kept out of training for good. Each one is predicted from day 0 using only its inputs, the same way a plan is predicted.
